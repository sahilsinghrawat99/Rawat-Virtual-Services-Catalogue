# RVS – Rawat Virtual Services

**A Modern Social Media Services & Premium Subscription Catalogue Website**

RVS (Rawat Virtual Services) is a responsive website designed to showcase digital marketing services and premium subscription plans at affordable prices. The website features a clean, modern interface inspired by professional SMM panels.

## 🌐 About the Project

This project provides customers with an organized catalogue of social media services, including YouTube, Instagram, Facebook, and X (Twitter), along with various premium digital subscriptions.

## ✨ Features

- Modern and professional user interface.
- Responsive design for desktop, tablet, and mobile.
- Social media service catalogue.
- Platform-wise service categories.
- Transparent pricing per 1K services.
- Premium subscription plans.
- Clean service listing layout.
- Modern gradient hero section.
- Easy-to-navigate design.
